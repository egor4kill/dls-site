# Как редактировать сайт ДЛС

Контент вынесен в два файла — `config.js` и `news.js`. HTML/CSS/`.js`-движок
трогать не нужно.

Сайт открывается двойным кликом по `index.html` — сервер не обязателен, но
если зальёшь на GitHub Pages или любой другой хостинг, всё точно так же
продолжит работать: `<script src="...">` грузится одинаково что с диска,
что с сервера.

## 1. `config.js` — тексты, цвета, ссылка на Telegram

Внутри — обычный JSON, обёрнутый в `window.SITE_CONFIG = { ... };`. Меняй
только то, что в кавычках `"..."`, первую и последнюю строку не трогай.

- `telegram.url` — ссылка на канал. Меняешь один раз — обновится везде:
  в шапке, в hero-кнопке, в CTA-блоке и на страницах новостей.
- `colors` — палитра сайта (hex-коды).
- `hero` — заголовок, подзаголовок, три цифры.
- `strip` — бегущая строка тезисов.
- `pillars` — четыре опоры программы (компас). У каждой:
  - `title` — заголовок опоры,
  - `recap` — короткая версия для карточки внизу страницы,
  - `items` — сами принципы, каждый как пара `{ "title": "...", "text": "..." }`:
    `title` — жирная короткая фраза, `text` — пояснение под ней. Раньше это
    был один слитный кусок текста, из-за чего вёрстка на широких экранах
    иногда наезжала сама на себя — теперь это две отдельные строки, наложений
    больше не будет при любой ширине текста.
- `quote` — цитата в разделе «Общество».
- `footer.copy` — копирайт.

## 2. `news.js` — новости, у каждой может быть своя страница

Формат — `window.SITE_NEWS = [ ... ];`, список объектов. Чтобы добавить
новость, скопируй один блок `{ ... }` и вставь его первым в списке (не забудь
запятую после закрывающей `}` предыдущего блока).

Два варианта, как оформить новость:

**A. Отдельная страница на сайте (вкладка со своим URL)**
Заполни `slug` (латиницей, без пробелов, уникальный, например `"start"` или
`"tax-explained"`) и `content` — массив абзацев текста. Больше ничего делать
не нужно: карточка на главной сама поведёт на `article.html?slug=...`,
страница соберётся автоматически из этих же данных. Никакой отдельной
привязки, файлов страниц создавать не нужно — один слуг = одна готовая
страница.

```js
{
  "date": "2026-08-20",
  "title": "Заголовок новости",
  "excerpt": "Короткое превью для карточки на главной.",
  "slug": "moy-slug",
  "content": [
    "Первый абзац статьи.",
    "Второй абзац статьи."
  ],
  "link": ""
}
```

**B. Просто ссылка на пост в Telegram (без своей страницы)**
Оставь `"slug": ""` и `"content": []`, а в `link` укажи полный адрес поста —
карточка поведёт прямо туда.

Если не заполнены ни slug/content, ни link — карточка будет просто текстом
без клика.

- `date` — формат `ГГГГ-ММ-ДД`, сортировка по дате автоматическая
  (свежее — выше).
- На главной показываются последние 6 новостей.

## 3. Если что-то не отображается

`F12` → вкладка Console. Пропущенная запятая или кавычка в `config.js` /
`news.js` даёт `Uncaught SyntaxError` с номером строки — это самая частая
причина поломки.

## 4. Публикация

Файлы работают локально для проверки, но чтобы сайт был доступен другим —
залей всю папку на GitHub Pages (как «Полынь») или другой статический
хостинг. В коде для этого менять ничего не нужно.

## 5. Картинки

Замени `logo.png` и `mascot.png` на свои, оставив те же имена файлов.

## Структура файлов

```
index.html     — главная страница
article.html   — шаблон страницы одной новости (общий для всех)
config.js      — тексты, цвета, ссылка на Telegram  ← редактируешь
news.js        — список новостей                    ← редактируешь
style.css      — стили (не трогать)
script.js      — логика главной страницы (не трогать)
article.js     — логика страницы новости (не трогать)
logo.png, mascot.png — картинки
```
